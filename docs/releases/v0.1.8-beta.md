# v0.1.8-beta — Installer build-marker detection fix

[English](#english) | [繁體中文](#繁體中文)

## English

This release fixes the v0.1.7 installer incorrectly reporting the verified `31.1.2sl19b3` runtime marker as `unknown`. Inno Setup's text loader truncated the binary `obs.dll` data at NUL bytes. The installer now uses Windows PowerShell's binary-safe `ReadAllBytes` path to extract the marker while retaining the same fail-closed ABI policy.

The Gaussian blur plugin DLL is unchanged from v0.1.7. Existing scenes and filter settings remain untouched.

Installer SHA-256: `3BB6F49151289015D37C867EADCB928FC1EEFEF1CBC8FEB32D4630BBE6B7D2D7`

## 繁體中文

此版本修正 v0.1.7 安裝器將已驗證的 `31.1.2sl19b3` runtime marker 誤判為 `unknown` 的問題。原因是 Inno Setup 的文字讀取函式遇到二進位 `obs.dll` 內的 NUL 字元時會截斷內容。新安裝器改用 Windows PowerShell 的 `ReadAllBytes` 安全讀取二進位內容，同時保留原本「遇到未知 ABI 就拒絕安裝」的安全規則。

高斯模糊外掛 DLL 與 v0.1.7 相同，不會修改既有場景與濾鏡設定。

安裝檔 SHA-256：`3BB6F49151289015D37C867EADCB928FC1EEFEF1CBC8FEB32D4630BBE6B7D2D7`
