# v0.1.7-beta — Streamlabs Desktop 1.21.7 compatibility

[English](#english) | [繁體中文](#繁體中文)

## English

This release restores Pure Gaussian Blur rendering on Streamlabs Desktop 1.21.7 by matching the native `31.1.2sl19b3` OBS runtime ABI. It preserves the existing `shader_filter` source ID and setting names, so existing scene/filter settings do not require migration.

Safety changes:

- The installer checks the numeric `obs.dll` version and exact `31.1.2sl19b3` build marker before replacing files.
- The plugin repeats the same fail-closed runtime check before source registration.
- The previous broad 31.1.x compatibility claim from v0.1.6 is superseded by exact verified-build compatibility.

Validated: Windows x64, Streamlabs Desktop 1.21.7, `obs.dll` 31.1.2, runtime API 31.1.3, build marker `31.1.2sl19b3`.

Installer SHA-256: `0B8F1424D8CEFE11AAD3570FDCEF1AB63D868F75B9E68C67C7AD44C0525403B7`

## 繁體中文

此版本依照 Streamlabs Desktop 1.21.7 使用的原生 OBS runtime ABI `31.1.2sl19b3` 重新編譯，恢復「純高斯模糊」的實際渲染。既有的 `shader_filter` 識別碼與設定名稱保持不變，使用者不需要搬移場景或重新設定濾鏡。

安全性調整：

- 安裝器在取代檔案前，同時檢查 `obs.dll` 數值版本與精確的 `31.1.2sl19b3` build marker。
- 外掛在註冊濾鏡前再次執行相同的安全拒絕檢查。
- v0.1.6 對所有 31.1.x build 的廣泛相容聲明已由「精確驗證 build」取代。

已驗證：Windows x64、Streamlabs Desktop 1.21.7、`obs.dll` 31.1.2、runtime API 31.1.3、build marker `31.1.2sl19b3`。

安裝檔 SHA-256：`0B8F1424D8CEFE11AAD3570FDCEF1AB63D868F75B9E68C67C7AD44C0525403B7`
