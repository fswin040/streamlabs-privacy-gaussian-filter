# v0.1.6-beta — Streamlabs Desktop 1.21.4

第一個公開測試版，已在 Windows x64 的 Streamlabs Desktop 1.21.4（內建 `obs.dll` 31.1.2）完成實際圖片來源測試。

## 功能

- 純高斯模糊，強度可調
- 整個來源或自訂矩形區域
- 低、中、高品質
- 強度為零時略過處理
- 以指定區域與安全邊距減少 GPU 工作量

## 安裝

完全關閉 Streamlabs Desktop，再以系統管理員身分執行 `MotionFrostedGlass-Setup-0.1.6.exe`。此安裝檔未購買程式碼簽章，因此 Windows SmartScreen 可能顯示警告。

> 僅支援 Streamlabs Desktop 1.21.4。請勿與其他使用 `shader_filter` 識別碼的外掛同時安裝。Streamlabs 更新可能移除或破壞此外掛。
