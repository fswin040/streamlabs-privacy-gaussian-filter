# v0.1.6-beta — OBS Core 31.1.x

## English

Public beta for Windows x64 Streamlabs Desktop builds embedding OBS Core API 31.1.x. The installer no longer requires an exact Streamlabs Desktop patch version: it validates the embedded `obs.dll` major/minor version, and the plugin checks the loaded OBS API again before registering the filter.

Validated on Streamlabs Desktop 1.21.4 with `obs.dll` file version 31.1.2 and runtime OBS API 31.1.3.

### Features

- True Gaussian blur with adjustable strength
- Full-source or custom rectangular region
- Low, medium, and high quality
- Zero-strength bypass
- Region-of-interest processing with a safe blur margin

Close Streamlabs completely before running `MotionFrostedGlass-Setup-0.1.6.exe` as administrator. The installer is unsigned, so Windows SmartScreen may display a warning. Do not install it alongside another plugin using the `shader_filter` source ID.
